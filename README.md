# Paving Mauritius Business Suite

## Deploy to Vercel (Step by Step)

1. Go to https://github.com and create a free account
2. Create a new repository called "paving-mauritius-suite"
3. Upload ALL the files from this zip
4. Go to https://vercel.com and sign in with GitHub
5. Click "New Project" → select your repository
6. Click "Deploy" — done!

Your app will be live at: https://paving-mauritius-suite.vercel.app
